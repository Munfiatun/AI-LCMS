# Phase 4 — Sensitivity and robustness protocol addendum v1.0
Pre-execution design; source Phase 3 archive commit f6cd99d8c5f198e6b56ad408c5996ee9e97623e0. Prior phase 2/3 verified run 45928359249, 1480 paired baseline profiles, 1542 numerical checks. Use D1–D4 only for Phase 4. Every shard rechecks its 1480 baseline outputs against archived actual rows (action, target, reason, selected, centroid, fired rules); input/config hashes checked. No changes to production engines, configuration files or prior research.
 
## OAT sensitivity
99 candidates: 15 Rule-Based (12 threshold shifts and 3 minimum-evidence alternatives; 2 is unchanged baseline); 84 fuzzy single-knot candidates (28 per input variable). Fixed endpoints stay fixed, strict inner ordering; 15 evidence candidates invalid and excluded before execution, 84 valid total (15 Rule-Based, 69 fuzzy). Full machine-readable list includes rejected candidates and reasons. Each valid variant executes all 1480 profiles. Planned 124320 variant calls. Distinct runtime registry code/version for every variant; immutable original definitions; only one extra definition exposed per call, transaction rolled back, original config restored. No tuning or selecting favorable results. Shape-valid variants may introduce uncovered regions: retain and count zero-fired-rule outcomes, do not silently discard or repair. Fuzzy targeting parameters remain fixed per frozen protocol.
 
## Robustness
For each of both algorithms, vary current mastery and each observed prerequisite mastery separately by ±1,3,5; current evidence and each observed prerequisite evidence separately by ±1. 24 planned perturbation slots per profile/algorithm; 71040 rows total, including skipped rows. Missing/absent prerequisite values not perturbed; clipping to [0,100] for mastery and lower bound 0 for evidence. Clipped no-change and not-applicable recorded without engine calls, excluded from decision/target stability denominators. Changed-but-clipped inputs included. Other values, graph and next context fixed. All actual engine calls use baseline version. 8880 baseline rechecks across six independent shards, not counted as new independent profiles.
 
## Metrics and evidence
PSR = changed final action / successful variant calls; DSR = unchanged final action / successful changed-input calls; target and joint stability analogous. Report counts, denominators, failures, not applicable, clipped no-change and zero-rule count. Breakdown by variant, dataset, signed delta and magnitude for robustness. Pooled summaries weight valid tested variants/slots, not populations; differing number and types of parameter variants do not support direct claims of superior robustness. Matched input perturbations are appropriate for descriptive cross-algorithm comparison. No claim of accuracy/pedagogical validity. Failure rows retained; gate requires baseline replay and complete planned keys, zero execution failures; zero-rule variants reported as diagnostic findings not execution failures. No human data or expert judgments. Separate six jobs on isolated SQLite memory; aggregate original actual CSVs, no artificial results. Artifacts retained 90 days; archive after verifying completed workflow. No merge.
