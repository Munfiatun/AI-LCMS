# AI-LCMS computational evaluation — protocol v1.0
Status: design recorded before comparative execution; Phase 0/1 only. Target JTI (SINTA 2 aspiration, not guaranteed). No human participants, expert assessment, or pedagogical claims. Institutional and coauthor approval for publication remains separate.

## Research questions and scope
RQ1 compare final actions and resolved concept targets under identical synthetic profiles. RQ2 assess sensitivity to parameter changes and small input changes. RQ3 assess robustness, execution failures and specification properties. RQ4 verify numerical implementation against an independently coded reference using the same frozen specification. RQ5 compare end-to-end computational cost. No directional superiority hypothesis. This is a computational study, not R5 expert validation or R6 learning-effectiveness research.

## Data generating mechanisms
D1 systematic grid 6 x 8 x 7 = 336; D2 boundary grid 8 x 4 x 4 = 128; D3 16 adapted R5 profiles; D4 five seeded blocks of 200 = 1000. D5 eight reference cases excluded from comparison totals. 1480 planned paired profiles (2960 base calls), possible overlap across groups; no pooling as independent observations. See experiment.json and DATA_DICTIONARY.md. Scores are integer hundredths of 0–100; D4 draws scores and nonnegative evidence independently (exploration, not empirical student distribution). Seeds 42,123,456,789,2026; LCG32 with rejection sampling, stratified 5 prerequisite patterns x 5 next contexts x 8 each per seed. This PRNG is for reproducibility, not cryptography. Missing prerequisite rows distinct from observed zero. All current mastery rows exist, including S01 zero evidence; absent current mastery is an additional property-test case. No personal data.
D1 and D2 use one prerequisite with evidence 3 and a ready next candidate; D3 fills unspecified prerequisite evidence as 3 and unspecified next context as ready; S13 none, S14 dual_blocked (one of two next prerequisites weak). These are explicit experimental fixture choices, not original expert answers. D5 prerequisite 100 denotes no prerequisite for first seven reference cases; eighth has one observed prerequisite score 30, evidence 3. D5 selected fuzzy output is not final action.

## Evaluation plan
Primary comparison: per dataset paired final-action agreement and divergence, target agreement, action+target agreement, 6x6 cross-tab and marginal counts; no accuracy, precision, recall or F1 absent independent labels. Denominator: successful pairs, with planned count and failures separately. Report all group-specific results, no inference to real learners. Secondary: Cohen kappa as descriptive machine agreement (undefined if degenerate); do not assume deterministic grid cases independent. For D4 summarize by seed and context.
Numeric: 8 reference centroid comparisons tolerance 0.00015, mean and max absolute error; nonzero case rule coverage plus count of distinct rule IDs out of 15. No pedagogical gold standard.
Sensitivity: one-at-a-time Rule-Based low/medium/prerequisite thresholds ±5 and ±10 points; minimum evidence 1,2,3,4. Fuzzy mastery internal knots ±5/10, prerequisite internal knots ±5/10, evidence internal knots ±1/2; reject invalid shape/order/domain, report skipped variants; fixed endpoints stay fixed, triangular strict order, trapezoid inner order with shoulder equality only at outer boundaries. Define exact variant list before running Phase 4; new codes/config hashes. Report fraction final action changes and target changes against each engine baseline per variant. Do not interpret higher sensitivity as worse by default.
Robustness: perturb mastery and observed prerequisite scores separately ±1,3,5 (clamp to 0–100, count no-change due to clipping separately), evidence ±1 (floor 0), no perturbation to missing entries. Report decision stability by variable and magnitude, target stability, failures and denominator. 
Metamorphic relations: identical inputs yield same action/target; evidence 10 vs >10 yields same fuzzy membership/centroid for otherwise identical context; repeat generator/decision with fixed seed/config. Properties: valid six action codes; target same course; crisp 0–100; Rule-Based insufficient evidence requests diagnosis; fuzzy fallback when selected next unavailable; next target satisfies readiness; nonzero fuzzy rule activation. Record applicable/pass/fail/not-applicable per property. No monotonic ordinal assumption for action categories.
Benchmark: fixed D4 1000 cases, 3 warmup and 10 measured batches per algorithm, alternating order, same hardware/process policy/fixture, exclude fixture setup and CSV writing from timed engine call; record DB and registry overhead as end-to-end; hrtime(true), median/mean/IQR/p95, throughput, failure, memory peak per isolated process. Shared CI only smoke/reproducibility, final timing on stable hardware. 
Outputs: comparative_results.csv, numerical_results.csv, sensitivity_results.csv, robustness_results.csv, metamorphic_results.csv, benchmark_results.csv, summary_metrics.json, run_manifest.json, figures. Not generated in Phase 1.
