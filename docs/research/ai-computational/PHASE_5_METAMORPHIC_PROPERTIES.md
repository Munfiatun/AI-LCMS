# Phase 5 — Metamorphic and property-based testing, protocol addendum v1.0
Pre-execution design. Frozen source: b8509615f2365e071e1779c168d343a570067f09. Phase 2/3 source run 45928359249; Phase 4 run 45933537326. Only branch research/ai-computational-evaluation. Guarded SQLite :memory:, unchanged engine classes, immutable baseline configs, no real people. Every observation uses a freshly rebuilt logical fixture and rolls back. No inference about learning outcomes.
 
## Relations
MR01: repeat each of 1480 profiles for both algorithms, compare entire normalized decision snapshot (action, target code, reason, membership, activation, centroid, fired rules, target readiness and version). 2960 pairs; excludes database IDs/timing. MR02: for every profile set current evidence to 10, compare otherwise identical profiles with evidence 11 and 20; fuzzy inference metadata and resolved action/target unchanged. 2960 pairs. MR03: fresh baseline decision compared to archived Phase 2 replay by case and engine; 2960 pairs; compare output, target, reason, centroid, selected label, fired IDs. Generator reproducibility checked by two independent generation runs with byte equality to frozen inputs. MR04: controlled fuzzy mastery 90, evidence 3, no current prerequisite; ready next concept vs absent, blocked, dual-blocked. Inferential output same, final ready next N vs enrichment C. Three paired checks. MR05: outcome-selected confirmation of 306 earlier zero-rule variant observations, replay same variant code/version and same profile, compare archived output. This is not a random sample or an estimate of general zero-rule risk.
 
## Properties
P01 six valid actions; P02 actual target exists in same course; P03 fuzzy finite centroid in [0,100]; P04 baseline Rule-Based missing current mastery or evidence below 2 -> diagnostic at C; P05 when fuzzy selected next and next is unavailable -> enrichment at C; P06 actual next target active, later in course and all prerequisites have evidence >=2 and mastery >=70; P07 baseline fuzzy nonzero rule activation. P08 stress-only zero-rule fallback diagnostic at C. Conditional properties explicitly not applicable when antecedent false. Engine/instrument failures status error, never counted as passes. Additional absent-current-mastery checks on all 16 D3 profiles for both algorithms, plus three targeted fallback profiles. No assumed ordinal monotonicity.
